# MathMaster - Interactive Math Learning Website

A modern, engaging web application designed to help students learn mathematics through interactive lessons and practice exercises.

## Features

### 🎯 Interactive Learning
- **Dynamic Math Problems**: Real-time generation of addition, subtraction, multiplication, and division problems
- **Difficulty Levels**: Easy, Medium, and Hard modes to match student skill levels
- **Instant Feedback**: Immediate response system with encouraging messages and explanations

### 📚 Structured Lessons
- **Lesson Library**: Organized math topics from basic arithmetic to advanced concepts
- **Progress Tracking**: Visual progress bars for each lesson
- **Word Problems**: Real-world applications of mathematical concepts

### 📊 Progress Analytics
- **Performance Metrics**: Track accuracy, problems solved, and learning streaks
- **Visual Charts**: Interactive progress visualization
- **Activity History**: Recent problem-solving activity with timestamps

### 🎨 Modern Design
- **Responsive Layout**: Optimized for desktop, tablet, and mobile devices
- **Clean Interface**: Intuitive navigation and user-friendly design
- **Animations**: Smooth transitions and engaging visual feedback

## How to Use

1. **Getting Started**
   - Open `index.html` in your web browser
   - No installation or setup required - it's a standalone web application

2. **Navigation**
   - Use the navigation bar to switch between Home, Lessons, Practice, and Progress sections
   - Keyboard shortcuts: Press 1-4 to quickly navigate to different sections

3. **Practice Mode**
   - Select your difficulty level (Easy, Medium, Hard)
   - Solve math problems in real-time
   - Press Enter or click Submit to check your answer
   - View your performance statistics

4. **Lessons**
   - Browse available math lessons
   - Click on any lesson to start practicing related problems
   - Track your progress for each topic

5. **Progress Tracking**
   - View your overall statistics and accuracy rates
   - Monitor your learning streaks and achievements
   - Review recent activity and problem-solving history
